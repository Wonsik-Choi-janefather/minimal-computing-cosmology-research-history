이 웹판은 최소계산 우주론과 Wonsik Reality Renderer Architecture의 연구 계보를 한글로 공개한다. 질문, 구조 발견, 계산, 반례, 수정, 실패한 경로와 열린 과제를 연구 순서대로 보존한다.

## 고정 판정규칙

모든 주장은 **검증 입력 → WRRA 고유 변환 → 산출값 → 반증조건**의 순서로 읽는다. 검증된 상수와 관측값을 반영한 모형 수정은 정당한 이론 구성으로 취급한다. WRRA가 자체 구조로 알려진 값을 재현하면 현실 정합성과 설명 성과로 판정하며, 독립예측을 이론의 필수조건이나 독창성의 기준으로 요구하지 않는다.
