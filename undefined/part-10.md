# 제10부 WRRA Game 1.0과 유한상태 검증의 성립

## 제10부 WRRA Game 1.0과 유한상태 검증의 성립

구성적 사례에서 전수검증과 실제 행동선택 엔진으로 이어진 새 응용 계보를 검증등급과 함께 고정한다.

## 91장 직관과 방향 전환 v3.0의 방법론 감사

2026년 9월 15일의 「WRRA 연구 프로그램의 직관과 방향 전환」 v3.0은 소수 필터에서 공통운반자, WRRA, 고정현재, 응용 연구로 이어진 판단 변화를 다시 대조했다. 새로운 물리 법칙을 추가한 문서가 아니라, 무엇을 구조 발견으로 보고 무엇을 검증 전에 OPEN으로 남겼는지를 정리한 메타 감사다.

핵심 변화는 최소계산을 무조건 가장 작은 모형으로 동일시하지 않게 된 점이다. 생존·합법성·상태전이의 정확성을 유지하기 위해 필요한 residue와 여분은 비용이 있어도 보존해야 한다. 이 원칙은 이번 Game 계보에서 ‘현재 판만으로 충분한가’를 전수 반례로 판정하는 형태로 더 명료해졌다.

주장 등급 STRUCTURAL. 연구 계보와 판정원칙의 일관성은 확인되었지만, 이 회고적 통합 자체가 우주론의 독립 경험적 검증은 아니다. 독립예측을 이론 성립의 필수요건으로 두지 않는 기존 입장과, 기존 FROZEN PREDICTION·PREREGISTERED TEST의 동결 계약을 모두 보존한다.

## 92장 WRRA Game 0.1: 구성적 오목·바둑 분석

WRRA Game 0.1은 Core 1.0을 바꾸지 않고 오목과 바둑을 서로 다른 Domain Profile로 구성했다. 자유형 오목은 현재 판과 차례만으로 다음 전이를 결정하지만, 단순 패 규칙의 바둑은 직전 판을 residue로 유지해야 되따내기를 금지할 수 있다. 과거 전체를 저장하지 않되, 현재의 합법적 실행에 필요한 정보만 보존한다.

9×9 자유형 오목의 지정 구성에서 71개 합법수를 조사했다. 중앙 (4,4)만 다음 차례에 네 개의 즉시 승리 출구를 만들었고, 백의 70개 합법 응답 가운데 네 출구를 모두 제거한 수는 0개였다. 이것은 Renderer가 법칙에 직접 쓰이지 않은 다중위협 phenotype을 구성할 수 있음을 한 사례에서 계산한 결과다.

5×5 바둑 패 구성에서는 residue를 보존할 때 합법행동이 18개, 제거할 때 19개가 되어 즉시 반복수 하나가 잘못 유입되었다. 여기서 residue는 미래를 예측하는 기억이 아니라, 지금 허용된 행동을 결정하는 현재 제약정보다.

주장 등급 EXACT(선언한 판·규칙·코드의 구성적 결과), STRUCTURAL(Core→Domain Profile 매핑), OPEN(표준 15×15 오목·19×19 바둑의 전역 해결과 일반 게임지능).

## 93장 WRRA Game 0.2: 최소 충분상태의 전수검증

0.2는 0.1의 사례를 유한 전체상태 검사로 확장했다. 상태표현 M이 충분하려면, M으로 압축된 두 이력이 같을 때 합법행동과 다음상태 갱신도 같아야 한다.

M(h₁)=M(h₂) ⇒ A\_legal(h₁)=A\_legal(h₂)

4×4 판에서 3목을 만드는 Connect K의 도달 가능한 6,036,001개 상태를 모두 열거했다. 기준 minimax와 증명된 Renderer 안전축약 minimax의 값 불일치는 0개였다. 빈 판 alpha–beta 노드는 기준 245,560에서 Renderer 순서화 15,686, 안전축약 32로 줄었으며 root 값은 같았다.

Σ\_{S∈S\_reach} 1\[V\_base(S)≠V\_WRRA(S)] = 0

η = 1 − 32/245560 = 0.9998697

3×3 단순 패 바둑은 현재 판·차례·직전 판·연속 패스 수를 포함한 132,161개 전체상태를 열거했다. 같은 보이는 판과 같은 차례에서도 직전 판에 따라 합법수 집합이 달라지는 동치류가 752개였고, residue를 제거했을 때 금지수 하나가 유입되는 완전상태는 768개였다. 가장 짧은 반례는 5수 뒤 같은 현재판에 도달한 두 이력이 서로 다른 합법수 집합을 가진다.

주장 등급 EXACT(선언한 유한 규칙계의 전수 상태수·minimax 불일치 0·residue 반례), STRUCTURAL(상태충분성·Renderer·residue의 역할 분리), CONDITIONAL(더 큰 규칙계로의 일반화), OPEN(독립 외부 재현·표준판 완전탐색).

## 94장 WRRA Go 0.1: 검증된 전이기에서 실제 착수로

WRRA Game 1.0은 0.2의 합법성·전이·residue 구조를 9×9에서 전수열거하는 대신, 각 합법수의 11개 Renderer 채널을 명시적으로 계산하고 MCTS가 제한된 시뮬레이션 예산 안에서 후보를 비교하게 했다. 탐색은 미래를 관측하는 예측이 아니라, 현재 규칙이 허용한 successor를 생성·비교하는 연산이다.

통제된 5×5 색상 교대 대국에서 WRRA Go는 균등 MCTS 대조군에 16국 15승 1패, 무작위 대조군에 16국 16승을 기록했다. 9×9 자기대국은 82수에 두 번 연속 패스로 종료되었고 백이 8.5집 차이로 승리했다. 코드·JSON 장부·SGF 기보·결정적 규칙검사·SHA-256 manifest가 재현 패키지에 함께 보존되었다.

이 수치는 전문 바둑엔진의 기력이나 현실세계 미래예측을 입증하지 않는다. 같은 규칙·판 크기·simulation 수·득점법 아래에서 투명한 Renderer가 실제 행동선택에 연결되고 대조 알고리즘과 비교 가능함을 보인 첫 실행시험이다.

주장 등급 EXACT(규칙검사·상태전이·기록된 코드 출력), CONDITIONAL/절제된 탐색(통제 대국의 15–1·16–0), STRUCTURAL(최소충분상태→Renderer→유한탐색→Ledger 사슬), OPEN(프로 기력·큰 판 일반화·외부 벤치마크).

## 95장 DOI 소유권 정정과 2026년 9월 21일 재진입 지도

이번 감사에서 새로 확인한 DOI는 Minimal Computing Cosmology 2.0의 10.5281/zenodo.22643792다. 최신 WRRA Core 1.0 동결본·출판본·Game 문서를 교차하면 10.5281/zenodo.22650956은 WRRA Core 1.0: A Domain-Agnostic Execution Architecture의 식별자로 일관되게 사용된다. 따라서 v7.0의 C67에서 의식·문명 연구에 붙였던 DOI 소유권은 Core 1.0으로 정정한다.

이 정정은 의식 응용의 계산결과를 폐기하는 것이 아니다. 무기억·순환기억·성공/실패 분리 residue의 비교, 지연단서 과제의 기억 이득, 복잡 결합과제의 약 50% 실패, 실제 의식·문명 일반화 OPEN은 그대로 보존한다. 다만 그 계보의 별도 DOI는 현재 확인되지 않은 것으로 적는다.
