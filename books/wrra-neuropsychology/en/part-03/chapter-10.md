# Chapter 10 Perception

### 1 Scene and question

We may mistake a distant stranger for someone familiar and correct the mistake on approaching. Perception can be studied as a process connecting input features, context, and previous experience. Illusions are both perceptual errors and tools for investigating the cues contributing to interpretation. (Spielman et al., 2020, §5.1 [R1](https://openstax.org/books/psychology-2e/pages/5-1-sensation-versus-perception))

Chapter question: Why does the same sensory input yield different perceptual judgments?

### 2 Starting points in established research

#### 2.1 Organizing parts into wholes

Perception research examines figure–ground separation and grouping by proximity or continuous contours. Such organization determines what is treated as a single object. (Spielman et al., 2020, §5.6 [R1](https://openstax.org/books/psychology-2e/pages/5-6-gestalt-principles-of-perception))

#### 2.2 Cues for depth and motion

Several cues are available for judging distance and motion. Restricting inputs helps identify what can be judged from the remaining cues. Choices when cues conflict help investigate combination rules. (Spielman et al., 2020, §5.3 [R1](https://openstax.org/books/psychology-2e/pages/5-3-vision))

### 4 WRRA-specific transformation

Transformation specification: distinguish input features from the weighting of experiential residue.

WRRA separates information already in a stimulus from residue the observer currently carries. Explaining rapid detection of an expected object in a familiar place requires manipulating visual features and expectations separately. Naming expectation does not specify an actual transformation.

#### 4.1 Combining expectations and current input

Reading an ambiguous letter differently across contexts illustrates investigating experience. Actual stimulus differences, contextual information, and response demands must be distinguished. Context can improve accuracy or reinforce mistaken expectations. Minimal computation evaluates rapid interpretation from limited input alongside misidentification costs under the same functional criteria.

#### 4.2 Organizing parts into wholes — WRRA interpretation

WRRA specifies input arrangements and relationships. Collecting features does not itself establish object meaning; the connection from grouping to actual judgment must be shown.

#### 4.3 Cues for depth and motion — WRRA interpretation

Transformations distinguish cue availability from weighting and record how weights are determined so they cannot be freely changed to match each result.

### 6 Falsification conditions and interpretive limits

Falsification condition: limit a claim of changed sensory experience if changes in verbal responses sufficiently explain the outcome.

An experiment might provide different prior information for the same ambiguous stimulus. Interpretation, accuracy, and confidence can be measured while the stimulus is held constant. Claiming changed sensory experience from changed interpretation requires additional supporting evidence.

#### 6.1 Learning rules from illusions

Rather than dismissing illusions as exceptions unrelated to normal perception, they can test which relationships and cues change outcomes. Size or contrast arrangements are varied systematically and judgments measured. WRRA evaluates whether one rule computes several arrangements. If every arrangement needs a separate rule, the scope of a common explanation narrows.
