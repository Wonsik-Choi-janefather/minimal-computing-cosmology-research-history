### 4 WRRA-specific transformation

Transformation specification: map Core elements to variables and observation paths in the field.

WRRA uses the name Wonsik Reality-Renderer Architecture. This book follows Core 1.0, frozen on 7 September 2026. Minimal computation reduces unnecessary states and processing while preserving required function and stability. A common carrier allows distinguishable information to share reusable transmission and updating structures. A phenotype is a result actually realized from an internal state under particular conditions.

#### 4.1 Reading a scene as an execution structure

Consider a hypothetical learner viewing a problem and selecting an answer. The displayed problem is input. Currently maintained information and bodily conditions constitute present state. Learning from earlier problems and the influence of failures can be treated as residue active now. The time limit and available answers are boundary conditions. The answer actually selected and the time taken become observed outcomes under those conditions.

Memory is recorded separately from present state to distinguish rapidly changing components from those carrying prior experience, not because they necessarily occupy physically separate locations. If residue is already included in the complete present state, the same information is not added again. Before adding variables, we must explain what new distinction they introduce.

#### 4.2 Defining minimal computation alongside function

Suppose one model stores every earlier trial, while another retains only a summary needed for the next choice. If both meet specified accuracy and stability criteria, memory, processing time, and the number of required relationships can be compared. Where no model minimizes every cost, several qualifying trade-offs may remain.

Minimal computation is distinct from the claim that the actual brain finds a global optimum at every moment. The design principle here is to seek a minimal implementation satisfying a particular task's requirements. A different task may require different memory. What is minimal must therefore be interpreted alongside the declared task and system boundary.

#### 4.3 What reusing a common carrier means

The same transmission network may process different information without erasing its identity. A proposed common carrier in this book must specify both the shared structure and the rules distinguishing channels. Observing a region involved in several functions does not establish the entire carrier structure.

One approach is to investigate interference between two tasks requiring shared resources. However, interference may also arise from instruction comprehension or response conflict. Experiments must distinguish its location. Common carrier is a principle for specifying sharing and differentiation together, rather than a label explaining all differences through one cause.

#### 4.4 Separating state updating from rendering

What has been learned and what can be demonstrated now may differ. Separate rules for the state update following learning and for reading current state as behavior can express this difference. Memory may persist while response time is insufficient; changed behavior does not by itself establish lasting learning.

An observation path also separates neural state from an experience report. Selecting a neural indicator as a candidate residue does not make that indicator the memory content itself. Connections among the indicator, learning conditions, and actual behavior require examination. Missing rules between explanatory levels remain research questions.

#### 4.5 Specifying resource dimensions and boundaries

Time, sleep, metabolic energy, attentional task capacity, and social support have different units. A study selects relevant dimensions and measures them directly or specifies valid proxies. Defining resource insufficiency solely from poor performance creates circularity by incorporating the outcome into the definition of its cause.

Boundaries also require differentiation. Physical boundaries created by bodily membranes or sensory organs differ in implementation from task response restrictions or workplace authority. If changing authority improves outcomes, the effect of a social boundary can be evaluated. It is not automatically recorded as an increase in an individual's internal resources.

#### 4.6 A ledger of records and ownership

Specifying who owns an experience, who owns an observation, and which model performed a computation makes the source of each achievement visible. A person's memory differs from a researcher's log, and an on-screen hint differs from internally maintained information. Use of external records requires including their access costs and availability among present conditions.

An execution ledger records input sources, rule versions, how coefficients were determined, outputs, and errors. If rules were adopted from an existing theory, this is stated along with the parts actually executed through WRRA's state and observation connections. Shared knowledge and computations performed within the framework can both be made transparent.

#### 4.7 From existing research to a WRRA application

In this application, present state means neural, bodily, and cognitive conditions involved in the current response. Residue is the influence of earlier events that remains active in the present. They are not physically isolated boxes. When the complete present state is recorded, residue may be a component, so definitions must prevent double counting. Records and their access paths must also exist in the present if they are to be read.

#### 4.8 Specifying an application against Core 1.0

The reference is WRRA Core 1.0, frozen on 7 September 2026. Its three invariants—minimum computation, the common carrier, and phenotype—and eleven required execution elements are retained. Minimum computation is Pareto-minimal cost subject to a declared function and error tolerance, rather than unconditional reduction of processing. [W1, §§0–3]

This revision specifies a neuropsychology Domain Profile without changing the Core. It prioritizes state-dependent interpretation, the perception–action loop, and the distinction between state estimation and control. History enters through presently instantiated state, residue, or accessible records, with ownership and duplication specified. A common carrier requires an explicit account of which channels share what; a proposed neural implementation requires separate testing. Appendix C2 provides the mapping, and C4 records the origins of suggestions.

### 6 Falsification conditions and interpretive limits

Falsification condition: rewrite variable definitions if correspondences are ambiguous or duplicated.

Relationships describe connections of influence; boundaries specify the inside and outside of a system and conditions of passage. Resources are made concrete as time, energy, available devices, support, and similar dimensions. One resource score does not replace them all. Changing a coefficient or measurement method in neuropsychology does not automatically change Core 1.0 definitions. Appendix A provides the detailed standard explanation.

#### 6.1 Conditions for completing an explanatory contract

Interpretation, computation, prediction, and control are distinct tasks in this book. A model explaining current data is assessed by which data it reproduces. Actual outputs derived from inputs and rules establish computational performance. Outputs for unmeasured conditions from a fixed model count as predictions; effects of interventions on state are validated separately.

A missing connection is left open. This separates what has been established from what needs further research rather than abandoning the whole explanation. Changes to field-specific coefficients or hypotheses leave minimal computation, common carriers, phenotypes, and Core execution principles intact unless separately revised.
