# Chapter 15 Memory Encoding, Retention, and Retrieval

### 1 Scene and question

Quickly forgetting a newly heard name may differ from knowing a name but being unable to retrieve it. Memory research distinguishes encoding during experience, retention over time, and retrieval when needed. Working and long-term memory also differ in roles and measurement tasks. (Baddeley, 2003 [R40](https://doi.org/10.1038/nrn1201); Spielman et al., 2020, §8.1 [R1](https://openstax.org/books/psychology-2e/pages/8-1-how-memory-functions))

Chapter question: Does poor memory performance originate in encoding, retention, or retrieval?

### 2 Starting points in established research

#### 2.1 Working and long-term memory

Working memory concerns maintaining and using information needed for a current task. Long-term-memory research examines knowledge, events, skills, and other contents. Distinctions in a model are not equated with physically isolated brain boxes. (Baddeley, 2003 [R40](https://doi.org/10.1038/nrn1201); Spielman et al., 2020, §8.1 [R1](https://openstax.org/books/psychology-2e/pages/8-1-how-memory-functions))

#### 2.2 Recall, recognition, and relearning

Uncued recall, recognition of presented items, and changes during relearning are different tests. Failure on one does not establish that every trace has disappeared. Conversely, correct recognition does not establish recall of all content and context. (Spielman et al., 2020, §8.1 [R1](https://openstax.org/books/psychology-2e/pages/8-1-how-memory-functions))

#### 2.3 Conditions of encoding and retrieval

Performance can depend on attention during learning and cues during retrieval. Explaining these processes requires separately manipulating learning-time and test-time conditions. (Spielman et al., 2020, §8.1 [R1](https://openstax.org/books/psychology-2e/pages/8-1-how-memory-functions))

#### 2.4 The scope of functional inference from lesions

Scoville and Milner reported cases of severe impairment in memory for recent experiences after bilateral medial temporal surgery. Clinical observations connecting surgical extent and memory performance provided evidence for investigating these structures' importance in memory formation. This differs from concluding that all memory is stored in one place. (Scoville and Milner, 1957 [R10](https://doi.org/10.1136/jnnp.20.1.11))

Scope of evidence: the WRRA application separates post-learning state changes from test outcomes. The retention rate 0.85 in Chapter 41 is a hypothetical setting, not a neural constant estimated from these cases.

### 4 WRRA-specific transformation

Transformation specification: distinguish encoding, retention, and access paths.

WRRA treats memory as structures remaining in the present and contributing to subsequent processing. This does not combine every memory mechanism into one. Classic difficulties in recent-experience memory after medial temporal damage, including the hippocampus, are important evidence. (Scoville and Milner, 1957 [R10](https://doi.org/10.1136/jnnp.20.1.11)) They do not establish storage of all memory at one location.

#### 4.1 Physical implementation and levels of memory

Circuit and molecular research provides concrete bases for investigating retention mechanisms. (Kandel, 2001 [R26](https://doi.org/10.1126/science.1067020)) Correspondences between particular contents and circuit changes must be validated for the task and measurement. WRRA specifies trace ownership and timescale. Chapter 41's single decay value illustrates a minimal maintenance rule rather than a constant representing this complex implementation.

#### 4.2 Working and long-term memory — WRRA interpretation

WRRA preserves relevant research distinctions while specifying which information is accessible to present processing.

#### 4.3 Recall, recognition, and relearning — WRRA interpretation

An observation function must specify separately which state each test reads.

#### 4.4 Conditions of encoding and retrieval — WRRA interpretation

WRRA distinguishes differences in generated traces from differences in access paths. Equal recall rates do not establish identical underlying paths.

### 6 Falsification conditions and interpretive limits

Falsification condition: revise complete-loss interpretations if changed cues restore performance.

Currently inaccessible content may become retrievable with different cues. Low recall must therefore be distinguished as possible residue loss or an access problem. Chapter 41 computes only one aspect of retention; it does not reproduce all actual memory or hippocampal function.
