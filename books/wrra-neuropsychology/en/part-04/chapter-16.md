# Chapter 16 Forgetting, Memory Reconstruction, and Updating

### 1 Scene and question

Retelling a memory may fill gaps or change emphasis. Later information, current questions, and memory for the original context may influence reports. Confidence and factual accuracy require separate examination. (Johnson et al., 1993 [R41](https://doi.org/10.1037/0033-2909.114.1.3))

Chapter question: How can trace changes be distinguished from present reconstruction?

### 2 Starting points in established research

#### 2.1 Separating time and interference

Other experiences occur as time passes. Poorer delayed memory may mix decay, interference, and changed retrieval cues. Controlling intervening activity or comparing interference conditions narrows candidate causes. (Spielman et al., 2020, §8.3 [R1](https://openstax.org/books/psychology-2e/pages/8-3-problems-with-memory))

#### 2.2 Remembering information sources

Familiarity with content differs from knowing where it was encountered. Misattributing a source can produce confident beliefs inconsistent with actual events. Content accuracy, source accuracy, and confidence are measured separately. (Johnson et al., 1993 [R41](https://doi.org/10.1037/0033-2909.114.1.3))

#### 2.3 Testing memory updating

If later reports change after memory is reused, researchers must compare added information and altered access paths. Reactivation and a changed trace are not treated as identical. (Johnson et al., 1993 [R41](https://doi.org/10.1037/0033-2909.114.1.3))

#### 2.4 Scope of a review on source judgments

Johnson and colleagues reviewed the source-monitoring framework and related experiments about judging where experiences originated. They distinguished content familiarity, source judgments, and the experiential properties and criteria used in those judgments. The review compared phenomena such as eyewitness reports and misattributed familiarity within one framework. (Johnson et al., 1993 [R41](https://doi.org/10.1037/0033-2909.114.1.3))

Scope of evidence: ownership distinctions in WRRA's ledger are model specifications preventing source confusion, not themselves the neural mechanisms of human source memory.

### 4 WRRA-specific transformation

Transformation specification: connect retained traces with present reconstruction rules.

Residue is not a perfect recording. Reports arise through currently usable traces and reconstruction rules. Memory reconstruction does not make every report equally uncertain, however. Independent records and repeated tests should identify what can be checked.

#### 4.1 Separating time and interference — WRRA interpretation

WRRA records actual intervening inputs rather than explaining all forgetting solely by update counts.

#### 4.2 Remembering information sources — WRRA interpretation

Ledger ownership supports these distinctions as a research principle; it is not assumed to perform the same function as psychological source memory.

#### 4.3 Testing memory updating — WRRA interpretation

WRRA specifies existing traces, new inputs, and maintenance and output rules. Claims about a particular updating mechanism require experiments distinguishing change timing and conditions.

#### 4.4 Separating content provenance and change history

Drawing on source-monitoring research, distinguish the original experience, later information, recalled content, and the source attributed by the person recalling it. Score content errors and source confusions separately; preserve change history in a presently accessible RECORD maintained by the researcher. Event identifiers, versions, modification times, and ownership are computational design choices, not claims that the brain stores those literal IDs or ledgers. A source-preserving model must still be revised if it cannot reconstruct condition-specific confusion distributions within tolerance. [R41; W1, §§2.1–2.2]

### 6 Falsification conditions and interpretive limits

Falsification condition: leave a particular memory-mechanism verdict open if no discriminating test is available.

Computing forgetting requires distinguishing elapsed time, interference from other learning, and changed cues. Several causes can generate the same recall curve, so one curve does not identify a mechanism. WRRA connects residue maintenance and expression without continually adding unobserved traces to explain every failure.

#### 6.1 Everyday memory and independent records

Calendars and message records can supplement memory as external resources. Where they conflict with recall, the times and contexts each reflects should be examined. External records may also be incomplete or edited and are not automatically absolute standards. Independent evidence can narrow factual possibilities, but confidence does not fill evidential gaps.
