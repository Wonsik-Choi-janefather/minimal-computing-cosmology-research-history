# Appendix B Terminology Correspondences

These are proposed research correspondences, not universally one-to-one identities between WRRA and disciplinary terminology.

| Core element | Proposed neuropsychological correspondence | Distinction to examine |
| --- | --- | --- |
| SOURCE | Sensory and bodily inputs; task information | External input versus internal state |
| RELATION LAW | Connections and permissible transition rules | Statistical versus causal relationships |
| STATE | Current neural, bodily, and task states | Complete state versus measured components |
| RESIDUE | Experiential influences active now | Residue maintenance versus retrieval access |
| BOUNDARY | Bodily, task, and social constraints | Physical versus rule-based boundaries |
| COMMON CARRIER | Reused transmission and updating structures | Shared infrastructure versus signal identity |
| UPDATE | Learning, adaptation, and state updating | Current response versus lasting change |
| RENDERER | Rules from internal state to expression | State updating versus output rules |
| PHENOTYPE | Implemented actions and responses | Possible versus actual outcomes |
| OBSERVABLE | Self-reports, behavior, and physiological measurements | Measurement versus experience itself |
| RECORD LEDGER | Experience records and measurement/computation ledgers | Personal memory versus external records |
