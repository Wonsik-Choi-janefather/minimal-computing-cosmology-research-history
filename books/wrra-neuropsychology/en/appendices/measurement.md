# Appendix C Measurement and Variable Specifications

Models record ownership, units, timing, measurement methods, errors, and possible duplication when defining variables. The following are examples of specifications to prepare, not actual research data.

| Item | What to define |
| --- | --- |
| Present state | State immediately before response, observation time, and scope |
| Experiential residue | Which experience's influence; maintenance and activation indicators |
| Available resources | Concrete dimensions such as time, sleep, and support; measurement methods |
| Relationships and boundaries | Influence direction, possible actions, and external conditions |
| Updating coefficients | Hypothetical, measured, or calibrated values |
| Output rules | Functions connecting state to reports and choices |
| Missingness and exclusions | Timing, prespecified criteria, and sensitivity analyses |
| Falsification thresholds | Evaluation measures, tolerances, and repeated-failure criteria |

Initial work may use neutral tasks without strong emotional stimulation. Person-level repeated trials record experience order and resources separately while controlling current difficulty. Sample sizes and tolerances are fixed beforehand based on expected effects, measurement variation, and purpose. No actual recruitment or data collection occurred for this manuscript.

Identifiability checks examine whether different coefficient combinations yield the same outputs. Unobserved residue requires fixed scale and sign references. Adding a neural indicator does not by itself establish its identity with a latent variable; this requires separate validation.
