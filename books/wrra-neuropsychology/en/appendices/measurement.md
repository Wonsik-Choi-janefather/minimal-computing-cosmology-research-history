# Appendix C Measurement and Variable Specifications

Models record ownership, units, timing, measurement methods, errors, and possible duplication when defining variables. The following are examples of specifications to prepare, not actual research data.

| Item | What to define |
| --- | --- |
| Present state | State immediately before response, observation time, and scope |
| Experiential residue | Which experience's influence; maintenance and activation indicators |
| Available resources | Concrete dimensions such as time, sleep, and support; measurement methods |
| Relationships and boundaries | Influence direction, possible actions, and external conditions |
| Updating coefficients | Hypothetical, measured, or calibrated values |
| Output rules | Functions connecting state to reports and choices |
| Missingness and exclusions | Timing, prespecified criteria, and sensitivity analyses |
| Falsification thresholds | Evaluation measures, tolerances, and repeated-failure criteria |

Initial work may use neutral tasks without strong emotional stimulation. Person-level repeated trials record experience order and resources separately while controlling current difficulty. Sample sizes and tolerances are fixed beforehand based on expected effects, measurement variation, and purpose. No actual recruitment or data collection occurred for this manuscript.

Identifiability checks examine whether different coefficient combinations yield the same outputs. Unobserved residue requires fixed scale and sign references. Adding a neural indicator does not by itself establish its identity with a latent variable; this requires separate validation.

## C2 Core 1.0 application checklist

This is a Domain Profile specification to complete for each task, not an established neural-mechanism model. The reference is W1 §§0–3; Chapter 2 §4.8 summarizes the three invariants. Concrete implementation and empirical verdicts remain separate.

SOURCE — Distinguish stimuli, prior instructions, external information, and interventions; record their origins and presentation times.

RELATION / LAW — Specify permitted influences and delays linking input, state, action, and subsequent input.

STATE — Define the memory, attention, bodily, and other states assumed to exist immediately before response, their owners, and estimation methods.

RESIDUE / CARRY — Specify currently retained effects of earlier experience and their maintenance or decay, without counting the same effect twice in STATE.

BOUNDARY — Define which person, task, device, and environmental processes are included, available actions, and open information pathways.

COMMON CARRIER — Declare which channels reuse which transmission/update scaffold while preserving channel identity, ownership, and destination. A shared model data structure and a biological carrier are separate hypotheses.

UPDATE / TAKEOVER / RESET — Specify next-state rules, intervention effects, resets, and carryover between trials.

RENDERER — Define how current state and boundary produce judgment reports, choices, or actions.

PHENOTYPE — Define instantiated task-level outputs, distinct from latent state and merely possible outputs.

OBSERVABLE — Define sensor values, behavioral logs, reported scales, and measurement errors. Experience and reports of experience are not identical.

RECORD / LEDGER — Preserve timing, provenance, costs, versions, and ownership; define which stored records are accessible in the present.

After fixing rules, declare target errors and budgets. Evaluate interpretation, computation, prediction, and control separately; unresolved data or causality leaves the relevant contract OPEN. Explanation, calibration, and reproduction of known results count within their declared scope. Absence of a novel prediction alone does not negate architectural or explanatory contributions. [W1, §1.1, §2.3, §3]

## C3 An example of testing an exploratory connection

No established relation between zeta zeros and calcium signals is asserted here. The connection is an exploratory topic from a relayed informal suggestion, recorded in I4. [R70](https://doi.org/10.1038/35036035) reviews the spatial and temporal diversity of calcium signaling; it supplies measurement context, not evidence for a zeta correspondence.

A test must first specify which quantities of which zeros are compared with which calcium-signal features. Mapping dimensionless quantities to Hz requires an explicit timescale and transformation. Control sample selection, indicator kinetics, sampling, filtering, noise, null models, arbitrary matching, and multiple comparisons. Similarity obtained using scales chosen after inspecting the data remains exploratory. A claim about performance on new data requires fixing the transformation and evaluating that claim on separate data.

Statistical similarity, a generating mechanism, and intervention effects are separate contracts. Proposing calcium as a common carrier additionally requires specifying what is shared or transported across which channels and with what ownership. The zeta–calcium correspondence and its neural-mechanism link remain OPEN. No new numerical test or biological validation is reported here. [W1, §1.2, §2.3; [R70](https://doi.org/10.1038/35036035)]
