# 변경 기록

## v0.4 · 2026-10-19

- 45장 본문의 기존 연구 설명에 저자·연도와 문헌 번호를 연결했다. 교재는 절별, 논문은 DOI로 연결한다.
- 참고문헌 R35–R55를 추가하고 원연구·검토·메타분석·기관 안내의 근거 범위를 표시했다.
- 기존 연구와 WRRA 응용이 섞인 문단을 분리했다. 근거 범위를 넘는 표현은 저자의 모형 설계나 후속 가설로 정비했다.
- 서문과 부록 F에 본문 인용 기준을 추가했다. Core 1.0 정의와 8단계 장 구성 및 가상 계산의 판정은 유지했다.

# 개정 이력

## v0.3 2026년 10월 18일

10부 45장을 여덟 단계의 공통 집필 형식으로 재편했다. 기존 해설 본문 364개 문단을 유지하고 실제 수행과 연구 계획 및 주장별 판정을 구분했다. 부록 F에 WRRA 학문총서 공통 집필 계약을 추가했다. 편집된 Word 원고는 146쪽이다.

Core 기준은 WRRA Core 1.0이며 책의 편집 판본과 구별한다. 가상 계산은 인간 및 신경 자료의 경험적 검증과 별도로 판정한다.
