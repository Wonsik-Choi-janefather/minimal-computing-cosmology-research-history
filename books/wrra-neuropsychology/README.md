# WRRA 신경심리학

**현재 상태와 경험의 잔여에서 마음과 행동까지**

최원식 · 본문 근거 개정 0.4 · 2026년 10월 19일

이 책은 WRRA Core 1.0을 유지하면서 심리학의 주요 주제를 신경계의 구현과 연결하는 연구 초고다. 일반 심리학의 익숙한 순서로 현상을 살피고, 현재 상태와 경험의 잔여, 관계와 경계, 자원과 표현의 연결을 제시한다.

10부 45장을 WRRA 학문총서의 공통 집필 형식으로 재편했다. 기존 학계의 출발점과 WRRA 고유 변환, 실제 수행과 계획 및 현재 판정을 같은 순서로 읽을 수 있다. 부록 A부터 E의 표준 해설과 계산 및 문헌을 수록하고, 부록 F에 다른 학문에도 적용할 공통 집필 계약을 제시한다.
