# 부록 A WRRA 1.0 표준 해설

기준 문서 W1의 정의를 보존하고 W2의 도입 설명을 참고한 해설이다. 신경심리학에 관한 문장은 이 책의 응용이며 Core 1.0 자체의 변경이 아니다.

## A1 WRRA의 명칭과 출발점

WRRA는 Wonsik Reality-Renderer Architecture다. 이 표준 해설은 WRRA Core 1.0 동결본과 기존 저서의 설명을 바탕으로 신경심리학 독자에게 맞게 정리했다. 복잡한 현상을 정보, 관계와 규칙, 현재 상태, 실행과 관측의 층으로 구분하는 것이 출발점이다. 우주론에서 개발한 개별 수식과 채널 수를 모든 응용 분야의 필수 조건으로 가져오지 않는다.

## A2 최소계산

최소계산은 선언한 기능과 표현, 안정성 또는 생존 기준을 만족하는 데 필요한 만큼의 상태와 처리를 사용하는 원칙이다. 무조건 적게 계산한다는 뜻이 아니다. 필요한 구별을 지워 기능이 무너지면 결핍이며, 유지에 필요한 여유와 중복은 최소 비용에 포함될 수 있다. 무엇을 비용으로 셀지와 어느 기준을 유지할지를 먼저 명시해야 한다.

## A3 공통운반자

공통운반자는 서로 구별되는 채널이 재사용할 수 있는 전달 또는 갱신 구조다. 같은 기반을 사용해도 정보의 소유자와 경로, 목적이 같아지는 것은 아니다. 신경심리학에서는 여러 기능이 재사용하는 전달망 등이 후보가 될 수 있다. 실제 공유 구조를 확인하기 전에는 대응 가설로 남긴다. 단일 신경전달물질이나 특정 뇌 부위로 미리 확정하지 않는다.

## A4 표현형과 관측

내부 정보가 곧 관측 결과는 아니다. 현재 상태는 실행과 표현의 규칙, 경계 조건을 거쳐 표현형으로 나타난다. 관측값은 그 표현형을 특정 장치와 절차로 읽은 결과다. 신경 활동, 행동, 경험 보고의 구분은 이 원칙의 응용이다. 표현형과 관측값을 구현상 함께 다루더라도 둘을 연결하는 측정 절차를 생략하지 않는다.

## A5 전체 실행 구조

Core 1.0의 공통 구조는 SOURCE, RELATION과 LAW, STATE와 RESIDUE, BOUNDARY, COMMON CARRIER, UPDATE, RENDERER, PHENOTYPE, OBSERVABLE과 RECORD 및 LEDGER로 정리된다. 이는 반드시 일렬로 한 번만 실행되는 신경 처리 단계라는 뜻이 아니다. 실제 응용에서는 피드백과 병렬 처리, 반복 갱신을 명세해야 한다. 각 요소에 무엇을 대응시켰는지가 핵심이다.

## A6 고정현재와 잔여

과거의 영향이 현재 작동하려면 그 효과가 현재 상태나 잔여, 접근 가능한 기록으로 남아 있어야 한다는 실행 원칙이다. 과거 기록을 읽는 모형도 그 기록의 현재 위치와 접근 경로를 명시하면 사용할 수 있다. 잔여는 손상이나 부정적 경험만을 뜻하지 않는다. 학습한 기술, 익숙함, 신뢰와 적응의 흔적도 해당할 수 있다. 유지되는 이익과 부담을 각각 측정한다.

## A7 관계와 경계

관계는 어떤 요소가 어떤 규칙으로 다른 요소에 영향을 주는지 나타낸다. 경계는 시스템의 안과 밖, 허용되는 흐름과 차단되는 흐름을 명시한다. 몸의 물리적 경계, 과제의 행동 제한, 사회적 권한은 구현 수준이 다르므로 구분한다. 모든 제약을 하나의 경계 변수로 합치지 않는다. 외부 지원을 내부 능력으로 계산하지 않도록 시스템 범위를 고정한다.

## A8 소유권과 기록 장부

같은 숫자라도 무엇의 상태인지가 다르면 다른 변수다. 소유권은 정보, 자원, 기억과 출력이 어느 대상에 속하는지를 밝히는 원칙이다. 한 사람의 자기보고와 상대의 추정, 신경 측정과 행동 기록을 서로 대신 쓰지 않는다. 장부에는 값과 단위, 시점, 출처, 변환과 결과를 남긴다. 물리적 보존량을 계산할 때와 측정 책임을 기록할 때의 장부 역할도 구분한다.

## A9 해석 계산 예측 제어

해석은 현재나 기록된 정보를 사용해 대상을 복원하거나 설명하는 과제다. 계산은 정한 입력과 규칙으로 결과를 산출하는 과제다. 검증값으로 모형을 정한 후 아직 측정하지 않은 대상이나 조건을 산출하면 해당 모형의 예측으로 평가한다. 제어는 행동이나 개입을 선택해 이후 상태와 기능을 바꾸는 과제다. 알려진 결과의 재현은 정합성과 설명의 성과이며, 새 숫자가 없다는 이유로 의미를 없애지 않는다.

## A10 실패 폐쇄와 응용의 분리

필요한 입력과 규칙, 오차와 검증이 부족하면 완료한 범위만 판정하고 나머지는 열린 상태로 기록한다. 특정 응용의 실패와 Core 전체의 폐기는 같은 주장이 아니다. 신경심리학의 계수와 상태 정의를 고치는 것은 분야별 응용의 개정이며 Core 1.0의 자동 개정이 아니다. 이 책은 독립예측을 모든 설명의 필수 조건으로 요구하지 않는다. 각 성과는 검증 입력, WRRA 고유 변환, 산출값, 반증조건을 먼저 제시한 뒤 판정한다.

## A12 Core 2.1 확장 해설 — 구조와 표현형의 구분

이 절은 W3의 Core 2.1을 제11·12부와 연결하는 추가 해설이다. 위 A1–A11은 Core 1.0에 대한 기존 해설이며, 그 안의 표와 장 번호는 당시 판본을 읽기 위한 역사적 연결을 포함한다. 본 판에서는 종합 장이 45장에서 54장으로 이동했다. Core 1.0의 동결 원문과 제41·42장 및 부록 D의 기존 계산 규칙은 변경하지 않았다.

### A12.1 확장 이유와 기호

한 번의 출력뿐 아니라 실행 조직의 유지·수정·다음 실행으로의 계승을 다루기 위해 Core 2.1을 적용한다. G는 현재 구현된 관계·규칙·실행 능력의 구조적 관점이고 P는 현재 조건에서 실제로 구현된 표현형이다. G는 생물학적 DNA만을 뜻하지 않는다. 저장된 명세가 있다는 사실과 실행 가능한 구조가 존재한다는 사실도 구분한다.

상태는 S_k=(G_k, X_k, R_k, B_k, L_k)로 표기한다. X는 현재 작동 상태, R은 현재 남은 영향, B는 자원, L은 출처·실행 장부다. G는 X 안에 나타날 수도 있으므로 별도 관점으로 기록한다고 자원을 이중 계산하지 않는다. 경계는 Boundary, 공통운반자는 C, 읽기·관측은 O로 구분한다. Q(a|S_k)는 승인 게이트이며 상태의 추가 성분이나 의식 지수가 아니다. 이전 판본의 B·Q와 비교할 때 기호의 뜻을 먼저 대응시켜야 한다. [W3]

### A12.2 표현과 계승의 인터페이스

P_k=Render_D(G_k, X_k, R_k, Boundary_k, B_k, input_k)는 분야별 D에서 구조·상태·조건이 현재 출력으로 이어지는 인터페이스다. 같은 G도 상태·입력·자원에 따라 다른 P를 낼 수 있다. 출력 차이만으로 구조가 바뀌었다고 역추론하지 않는다.

G_(k+1)=Inherit_D(G_k, amendment_k, retained_state_k)는 다음 실행의 구조를 기록하는 인터페이스다. 분석 단위와 소유자, 운반자, 계승 항목, 허용 변경·수동적 변화의 허용치, 복원 절차와 적합성 검사를 선언한다. 장부에는 부모·후속 구조, 실제 변경과 근거, 비용 및 검사 결과를 남긴다. 손상이나 표류가 생겼다는 사실을 승인된 변경으로 정의하지 않는다. [W3]

### A12.3 자원과 개입

자원 j마다 B_j−Cbound_j(a)−Hbound_j(a)≥Reserve_j를 확인한다. Cbound는 행위 비용 상한, Hbound는 확인·기록·대응 비용의 상한이다. 실제 효과 전에 자원을 예약하고 확정 직전에 다시 검사하며, 거절된 제안의 검사 비용도 사라지지 않는다. 확인 미완료는 OPEN이며 Q=0, 실패는 DENY이며 Q=0이다. Q=0이 삭제·파괴 같은 다른 행위를 자동 허가하지 않는다. 대응 행동에는 별도 계약이 필요하다. [W3]

출력 개입은 현재 P를 바꾸지만 이후 G를 바꾸지 않을 수 있다. 구조 개입은 이후 실행의 조직을 바꾸며, 혼합 개입은 두 효과를 각각 기록한다. 기억이나 신경 조직의 어떤 변화가 어디에 해당하는지는 과제와 시간 척도에 맞춘 분야별 명세다.

### A12.4 의식 응용과의 경계

45장은 경험·기능·보고를, 48장은 재료와 조직 및 출력·구조 개입을, 49장은 생성·유지·계승을 구분한다. 50–53장은 시간·우주·집단·개인 연속성으로 질문을 확장한다. 그중 의식의 충분조건, 주체의 동일성, 영혼이나 환생은 Core의 정의에 포함된 사실이 아니다. 본서가 제안한 경험 보조 기호 E도 Core 원문의 새 상태 성분이 아니다.

Core 2.1의 유한 자원 시연은 배분 규칙의 출력 변경과 구조 수정이 다음 실행에서 다르게 이어짐을 보여 주는 참조 구현이다. 그 성공을 뇌나 의식의 검증으로 확대하지 않는다. 기존 1.0 응용 계산과 새 2.1 응용 설계를 별도 기록하고, 설명·계산·경험적 적합성·예측·제어의 계약을 구분한다. [W1, W3]
