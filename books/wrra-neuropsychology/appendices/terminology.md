# 부록 B 용어 대응표

아래 표는 연구를 위한 대응안이다. WRRA 용어와 기존 학문 용어가 항상 일대일로 같다는 뜻은 아니다.

| Core 요소 | 신경심리학의 대응안 | 확인할 구분 |
| --- | --- | --- |
| SOURCE | 감각 입력과 신체 입력 및 과제 정보 | 외부 입력과 내부 상태 |
| RELATION LAW | 연결과 허용 전이 규칙 | 통계적 관계와 인과 관계 |
| STATE | 현재 신경 및 신체와 과제 상태 | 전체 상태와 측정된 일부 |
| RESIDUE | 현재 작용하는 경험의 영향 | 잔여의 유지와 인출 접근 |
| BOUNDARY | 몸과 과제 및 사회적 제약 | 물리적 경계와 규칙의 경계 |
| COMMON CARRIER | 재사용되는 전달 및 갱신 구조 | 공유 기반과 신호의 구별 |
| UPDATE | 학습과 적응 및 상태 갱신 | 현재 반응과 지속적 변화 |
| RENDERER | 내부 상태에서 표현으로 가는 규칙 | 상태 갱신과 출력 규칙 |
| PHENOTYPE | 구현된 행동과 반응 | 가능한 결과와 실제 결과 |
| OBSERVABLE | 자기보고와 행동 및 생리 측정값 | 측정값과 경험 자체 |
| RECORD LEDGER | 경험 기록과 측정 및 계산 장부 | 개인 기억과 외부 기록 |
