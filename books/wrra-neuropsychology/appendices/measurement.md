# 부록 C 측정과 변수 명세

각 모형은 변수를 정의할 때 소유자와 단위, 시점, 측정 방법, 오차, 중복 여부를 함께 기록한다. 아래 항목은 실제 연구 자료가 아니라 작성할 명세의 예다.

| 항목 | 정의할 내용 |
| --- | --- |
| 현재 상태 | 반응 직전의 상태와 관측 시점 및 포함 범위 |
| 경험 잔여 | 어떤 경험의 영향인지와 유지 및 활성화의 지표 |
| 가용 자원 | 시간 수면 지원 등 구체적인 차원과 측정법 |
| 관계와 경계 | 영향의 방향과 가능한 행동 및 외부 조건 |
| 갱신 계수 | 가상 설정인지 측정값인지 보정값인지 구분 |
| 출력 규칙 | 상태가 보고와 선택으로 연결되는 함수 |
| 결측과 제외 | 적용 시점과 사전 기준 및 민감도 분석 |
| 반증 문턱 | 평가량과 허용 오차 및 반복 실패의 판정 기준 |

초기 연구는 강한 정서 자극이 없는 중립적 과제에서 시작할 수 있다. 사람별 반복 시행을 모으고 현재 과제 난이도를 통제하며, 경험 순서와 자원 조건을 구분해 기록한다. 표본 수와 허용 오차는 예상 효과와 측정 변동, 연구 목적에 따라 사전에 정한다. 이 초고에는 실제 참여자 모집이나 자료 수집이 없다.

식별성 점검에서는 같은 출력이 다른 계수 조합에서도 나오는지 확인한다. 잔여가 관측되지 않는 상태라면 척도와 부호의 기준을 고정해야 한다. 실제 신경 지표가 추가되더라도 잠재 변수와 동일한 것인지 별도로 검증한다.
