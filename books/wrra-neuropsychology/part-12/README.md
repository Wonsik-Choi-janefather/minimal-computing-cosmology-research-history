# 제12부 신경심리학에서 출발한 의식의 확장 질문

이 판의 제11부는 신경심리학과 의식 연구를 연결하고, 제12부는 신경심리학에서 출발한 의식의 확장 질문을 다룬다. 동물·인공 시스템은 비교인지과학과 계산적 의식 연구의 접점이며, 우주론적 필연성·영혼·환생은 검증 가능한 하위 주장과 철학적 해석을 구분해 검토한다. 이 확장부는 일반 신경심리학의 확립된 지식 목록을 넓혔다는 선언이 아니라 WRRA의 이종 학문 연결 가능성을 탐구하는 부분이다.

의식이 경험이라면 그 경험에서 시간이 이어지는 방식, 우주 안에서 그런 구조가 생기는 조건, 개인을 넘어 남는 기억과 구조의 지위도 물을 수 있다. 이 부는 이 질문들을 배제하지 않고 각각의 주장 단위로 나눈다. 철학적 해석, 알려진 연구의 결과, WRRA 응용의 명세, 아직 입증되지 않은 가설에 같은 판정을 주지 않는다. 기존 이론을 WRRA의 용어로 바꾸는 것과 실제 변환을 실행해 연결하는 것도 구별한다.
