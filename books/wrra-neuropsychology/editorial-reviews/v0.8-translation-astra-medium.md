# WRRA 신경심리학 v0.8 영문 번역·Core 연결 대조 심사

심사일: 2026-10-19. 성격: 출판 준비를 위한 자문 검수. 학술지의 공식 동료심사, Core의 공식 적합 인증, 경험적 타당성 인증이 아니다.

## 판정

**지적 사항의 수정이 반영된 영문 원고는 번역 정합성 기준에서 출판 가능하다.** 원문의 가설·계산·경험적 근거 구별, 45장 구성, 두 가상 계산의 성취와 한계, 기존값 재현과 보정의 가치가 보존되어 있다. 전반적 누락이나 과학적 지위의 체계적 과장을 발견하지 않았다. 아래 수정은 실제 의미 차이를 바로잡은 것이며 단순 문장 윤문만으로 처리하지 않았다.

이 판정은 Markdown 내용에 관한 것이다. 재생성한 Word/PDF의 페이지 구성, 표 잘림, 링크, 목차, 배포 파일 일치 확인은 별도 제작 검수다. 모든 외부 문헌을 새로 사실 검증했다는 뜻도 아니다.

## 검토 대상과 방법

한국어 `gitbook_payload_v07.json`을 기준으로 `english_v07/`의 45개 장, 서문, 안내, 색인, 10개 부 표제, 부록 안내, 부록 A–F 및 Core 연결 페이지를 읽었다. 디렉터리 이름의 v07은 작업 경로이며 출판본 표시는 v0.8이다. 한국어 연결표 `core_linkage_ko.md`와 공식 Core 원문에서 보존한 `core_source_v1_snapshot.md`를 대조했다. Core 원문에서는 연결표가 지시하는 정의·원칙·프로파일·적합 조건·버전 관리 절을 확인했다. 전체 응용 레지스트리의 독립 적합성 심사는 하지 않았다.

한국어 원고 전체에 대한 앞선 출판 심사와 별개로, 이번에는 번역으로 인해 주장 범위가 바뀌는지를 중심으로 읽었다. 원문의 대표사례 초안 작성에 심사자가 앞서 참여한 이력이 있으므로 완전히 외부적인 익명 독립 심사로 표시해서는 안 된다.

기계 대조에서는 45개 장 모두의 8단계 번호, 소절 번호, 문헌 식별자 집합, 소수 값의 출현 횟수를 다시 비교하여 일치를 확인했다. 소수 뒤 영문 마침표나 한글 조사의 유무로 생기는 정규식 경계 오탐은 제거했다. 판정 용어 및 계산값은 해당 문맥에서도 읽었다. 부록 D의 영문 Python 코드 블록을 추출하여 실행한 표준출력이 기존 `model_results_v07.txt`와 정확히 일치했다.

## 성취와 제한의 보존

41장은 유지율 0.85의 무차원 흔적 모형이며 실제 시간이나 회상확률로 이미 연결되지 않았다는 제한을 유지한다. 42장은 자원 1.0/0.3, 실패 전 확률 0.890903/0.813057, 다섯 실패 뒤 잔여 1.344640 및 확률 0.650422/0.497724를 그대로 보존한다. 45장 대표사례는 이 계산을 발언 장면의 설명 명세에 연결하지만 실제 발언 확률, 신경 회로, 치료 효과를 검증한 결과로 전환하지 않는다. 계산이 드러낸 미연결 부분과 추가 측정의 필요성도 남아 있다.

`COMPUTATIONAL PASS`와 경험적 입증을 구별하고, `INFERRED` 또는 열린 연결을 완료된 통합으로 격상하지 않았다. 기존 관측값의 보정·재현이 설명과 현실 정합성에 기여할 수 있다는 원문의 평가 기준도 보존한다. 새 예측이나 비교 우위를 모든 응용의 필수조건으로 새로 부과하지 않는다.

서문의 W2 저자명 Jeongin Choi와 부록 E의 Choi, Jeongin은 동일 인물의 표기 형식 차이로 일관된다. 한국어 최정인과 충돌하는 별도 영문 이름은 검토 범위에서 발견하지 않았다.

## Core1.0 연결표 평가

공식 원문과 연결표의 8개 절 대응은 적절하다: §1.1 최소계산, §1.2 공통운반자, §1.3 표현형 및 §2 필수 요소, §2.1 고정현재, §2.2 소유권, §2.3 실패 폐쇄, §3 프로파일 분리와 §7 버전 관리, §6·6.1 적합 조건. 연결표는 책의 장으로 독자를 안내하면서 비교 최소성 미입증, 공유 신경 구현의 가설 지위, 실제 실행한 계산으로 한정한 판정을 함께 표시한다.

A11은 설명용 대응표이며 동결된 Core 레지스트리의 추가 정의나 A1–A10의 대체 정의로 제시되지 않는다. 응용 계수와 관측 규칙을 고치는 일과 Core 개정을 구별한다. DOI를 보존 원문의 식별자로 설명하고 심사 통과나 경험적 검증의 보증으로 사용하지 않은 점도 타당하다.

Core §2.3의 PREDICTION 계약은 현재 정보로 미래 대상의 손실 또는 불확실성을 줄이는 성능을 요구한다. 따라서 고정 모형의 미측정 조건 산출을 조건부 예측이라 부르는 것만으로 그 계약을 검증했다고 할 수 없다. 이번 A11 주석은 이 차이를 정확히 밝혔으며, 모형의 설명 가치 자체를 부정하지 않는다.

대조 원문: [공식 GitHub Core1.0 원문](https://github.com/Wonsik-Choi-janefather/wrra-core/blob/main/WRRA_Core_1.0_EN.md), [보존 DOI](https://doi.org/10.5281/zenodo.22650956). 이번 작업에서는 주 작업자가 확보한 로컬 원문 스냅샷을 읽어 절을 대조했다. DOI 메타데이터나 원격 저장소 전체의 독립 보존 감사는 수행하지 않았다.

## 제작 단계에 남는 확인

교정된 Markdown으로 Word·PDF·GitBook·Zenodo 배포 파일을 생성해야 한다. 구버전 Word에 이번 교정이 자동 반영되었다고 가정하지 않는다. 연결표를 부록 A와 독립 페이지에 함께 제공할 경우 예측 범위 주석도 양쪽에 동일하게 유지해야 한다. 이러한 파일 동기화와 최종 인쇄 교정은 위 내용 판정과 구별된다.
