# WRRA 신경심리학 v0.10 개정 기록

2026년 10월 22일 · 최원식 · 국문 원고

기존 국문 v0.9에 제11·12부의 의식 관련 9개 장을 추가했다. 전체는 12부 54장이고 기존 종합 45장은 54장으로 이동했다. 모든 장의 8단계 형식을 유지했다.

추가 범위는 의식의 정의와 실험, 동물·인공 시스템의 의식, 생성·유지·측정, 엔트로피와 시간, 우주론적 필연성, 집단무의식, 영혼·죽음·환생이다. 신경심리학의 직접 연구 범위, 인접 학문, 철학적 확장 질문의 관계를 서문과 부 도입에 명시했다.

Core 1.0에서 출발한 기존 응용과 Core 2.1의 구조 G·표현형 P·구조 계승·개입 계약을 적용한 새 설계를 구분했다. 기존 부록 A는 보존하고 A12를 덧붙였다. Q는 승인 게이트이며 의식 지수가 아니다. G의 재현이나 계승을 동일한 경험 주체의 지속과 동일시하지 않았다.

추가 문헌 R71–R89와 저자 선행 저작 W3–W5를 본문에 연결했다. 경험과 접근의 구분은 Nagel·Block·Chalmers, 다차원 동물 의식은 Birch 등, 집단무의식은 Jung 등의 기여로 명시했다. 기존 I1–I4 제안의 간접 전달·미확인 출처 표시는 유지했다.

기존 41·42장 및 부록 D의 문서 구조와 수식·표는 원래 OOXML과 일치한다. 모든 기존 표와 재현 코드는 변경하지 않았다. 새 9개 장은 설명과 연구 설계이며 신규 신경 자료 분석·임상 시험·의식 발생 시뮬레이션은 수행하지 않았다. 기존 가상 모형의 COMPUTATIONAL PASS를 추가부로 확대하지 않았다.

이번 묶음은 국문 개정 원고, PDF, 추가부 원문, 편집용 국문 소스와 검증 기록이다. 영문은 기존 v0.9이며 이번 판의 번역 완료나 GitHub·GitBook·Zenodo 신규 게시 완료를 주장하지 않는다. 새 DOI와 외부 출판 심사 결과를 부여하지 않았다.
