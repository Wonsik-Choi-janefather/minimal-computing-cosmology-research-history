# Minimal Computing Cosmology 3.0

MCC 3.0 is the finite-source integrated release connecting a generated address space to components, energy, gravity, galaxy-scale observables and cosmic expansion.

**Status:** six-stage computational integration PASS / integrated scientific model PASS-C

**Zenodo DOI:** https://doi.org/10.5281/zenodo.23202732

This section contains:

1. the complete English integrated manuscript; and
2. a short cosmology and gravitation executive paper for astrophysics outreach.

The executive paper is intended as the first entry point for researchers in galactic dynamics, gravitation and cosmology. The full manuscript provides the upstream finite-source construction, component/particle layers, complete claim boundaries and reproducibility record.
